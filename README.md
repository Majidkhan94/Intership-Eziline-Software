# Internship - Eziline Software

Projects completed during my internship preparation, where I learned and practiced the complete **MERN Stack** (MongoDB, Express.js, React.js, Node.js) along with modern frontend development using Tailwind CSS.

🔗 **Live Demo:** [jsxpress.vercel.app](https://jsxpress.vercel.app)

## Tech Stack

- **Frontend:** React.js, Tailwind CSS, HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Vercel

## Projects

### Authentication_System
A complete authentication system covering login, registration, and protected routes — built to practice secure user authentication flows.
🔗 [Live Demo](https://authenticationsystem-green.vercel.app/)

### Homeland
A UI for a Sales and Rent website, focused on building a clean, responsive real estate browsing experience using React.
🔗 [Live Demo](https://homeland-silk.vercel.app/)

### JSXPress
A landing page built with React.js and Tailwind CSS, focused on modern UI design and responsive layouts.
🔗 [Live Demo](https://jsxpress.vercel.app/)

### ReactShop
An e-commerce platform built with React.js and Tailwind CSS, covering product listings, cart functionality, and a responsive shopping experience.
🔗 [Live Demo](https://reactshop-two.vercel.app/)

### ReactSphere
A restaurant website built with React.js and Tailwind CSS, focused on showcasing menus and restaurant information with a modern UI.
🔗 [Live Demo](https://reactsphere.vercel.app/)

### Travel Agency
A travel agency website built using HTML and CSS, focused on layout structuring and responsive design fundamentals.
🔗 [Live Demo](https://travelagency-orcin.vercel.app/)

## How to Run

Each folder is an independent project. To run any of them locally:

```bash
cd <project-folder>
npm install
npm run dev
```

## Purpose

This repository documents my journey of learning the MERN stack during my internship preparation — starting from frontend fundamentals (HTML/CSS) to building full React applications, and eventually integrating authentication and backend concepts with Node.js, Express, and MongoDB.
